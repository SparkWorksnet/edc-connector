Data Quality Checks

Optional
Select the quality rules you want to enforce on your dataset. The validation pipeline will evaluate each enabled rule and include the results in your dataset's description in the Staging Catalogue. Rules that fail will be reported; only critical failures block promotion to the Community Datasets Catalogue.
ExpectColumnValuesToNotBeNull Compulsory
A column must contain no null values. This check is always enforced.
ExpectColumnToExist Compulsory
A named column must be present in the dataset.
ExpectTableRowCountToBeBetween
Total number of rows falls within the specified range.
ExpectTableColumnCountToBeBetween
Total number of columns falls within the specified range.
ExpectTableColumnsToMatchOrderedList
Columns appear in the specified order with the specified names.
ExpectColumnValuesToBeNull
A column must contain only null values.
ExpectColumnValuesToBeOfType
All values in a column must be of the specified data type.
ExpectColumnValuesToBeInSet
All values in a column must belong to the defined set of allowed values.
ExpectColumnValuesToNotBeInSet
No values in a column may belong to the defined set of disallowed values.
ExpectColumnValuesToBeBetween
All values in a column fall within the specified numeric range.
ExpectColumnValuesToBeDateutilParseable
All values in a column can be parsed as valid dates.
